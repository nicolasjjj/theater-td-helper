劇場幫幫｜隱私權政策

最後更新：2026 年 11 月 27 日

「劇場幫幫」（以下稱本服務，網址 https://theater-helper.j7897063.workers.dev ）是給劇場工作者排班、找人、記錄時段與產生時段表的免費網頁工具。本服務盡量不經手你的資料，以下說明細節。

我們不保存你的資料

  • 你的案子、人員、場館、劇團等資料，存在你自己的 Google 雲端硬碟或 Notion 裡，本服務的伺服器不保存任何一筆。
  • 登入資訊與設定只存在你使用的瀏覽器（localStorage）裡。
  • 本服務不使用廣告、不做追蹤分析，也不會把任何資料賣給或提供給第三方。

使用 Google 帳號時

  • 本服務只要求 drive.file 權限：只能存取本服務自己在你雲端硬碟建立的檔案（「劇場幫幫」資料夾、資料試算表、時段表），看不到你雲端硬碟裡的其他檔案。
  • 另外取得你的電子郵件地址，只用來在設定畫面顯示「已登入哪個帳號」。
  • 登入時，伺服器會轉送一次 Google 的權杖交換（用來保管應用程式密碼），轉送內容不會被記錄或保存。
  • 本服務使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」的要求：資料只用來提供你看到的功能。

使用 Notion 時

  • 你在 Notion 建立的 API 權杖只存在你的瀏覽器裡。網頁透過同網域的轉送路徑連到 Notion 官方 API，轉送內容不會被記錄或保存。

停止使用與刪除

  • 在本服務的「⚙︎ 設定 → 登出並清除設定」可以清除瀏覽器裡的設定。
  • 到 Google 帳戶的「第三方應用程式和服務」移除「劇場幫幫」，即可撤銷授權；再刪除雲端硬碟裡的「劇場幫幫」資料夾，資料就完全刪除。
  • 使用 Notion 的話，到 Notion 刪除你建立的連接，權杖就會立即失效。
